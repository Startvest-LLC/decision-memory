# Closure Message Template

Use when a feature ships and you want to notify stakeholders.

## Template

```markdown
## Feature Shipped: [Title]

Hey [Name/Team],

Great news! The feature you requested is now live.

**What shipped**: [Brief description of what was built]

**Where to find it**: [Location, URL, or how to access]

**Your original request**: [Brief reminder of what they asked for]

Thanks for the feedback - it made our product better.

— [Your name/team]
```

## Example: Filled Out

```markdown
## Feature Shipped: API Rate Limiting

Hey Sarah (Acme Corp),

Great news! The API rate limiting feature you requested is now live.

**What shipped**: Configurable rate limits per API key with real-time usage dashboard.

**Where to find it**: Settings > API > Rate Limits

**Your original request**: "We need to prevent runaway scripts from hitting rate limits and getting blocked."

Thanks for the feedback - this will help all our enterprise customers manage their API usage better.

— The IdeaLift Team
```

## Tips

- **Be personal**: Use their name if you have it
- **Be specific**: Remind them what they asked for
- **Be grateful**: Acknowledge their contribution
- **Include access**: Tell them exactly where to find it
